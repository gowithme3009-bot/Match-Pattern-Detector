Détecteur & historique

Règle stricte : J A–B = 2-2 ; J+1 B reçoit et bat C, tandis que D reçoit et perd contre A ; J+2 C reçoit D. Seuls les matchs et scores confirmés sont utilisés.

Importation & exportation

Exporter tous les matchs au format JSON pour les sauvegarder ou les transférer.

L'importation accepte un tableau de matchs ou un objet contenant la propriété matches. Les identifiants existants sont remplacés si le même identifiant est importé.

Confidentialité & limites

Les données restent dans le stockage local de ce navigateur. Effacer les données du navigateur peut les supprimer : exportez régulièrement une sauvegarde JSON.

Cette application n'est connectée à aucun bookmaker. Elle ne récupère aucun résultat lorsque l'application est fermée. Le signal 1X est un indicateur expérimental basé uniquement sur l'historique saisi, pas une prédiction certaine ni une garantie de gain.
